Nạp việc làm & Facebook page

Chạy node tools/job-collect.mjs để lấy tin từ VietnamWorks & vieclam24h vào assets/data/job-feed.json. Facebook page cần Page access token (Graph API), TopCV/ITviec cần cookie — xem ghi chú.

Nguồn nào đáng dùng?

  • Chạy ngay: vieclam24h, VietnamWorks (đọc JSON server render, không cần key).
  • TopCV, ITviec: Cloudflare chặn bot — cần cookie cf_clearance từ trình duyệt của bạn.
  • Facebook page: cần Page access token (Graph API) hoặc dán JSON bài viết.
  • TikTok / IG / X: không có quyền truy cập công khai — để trống hoặc dùng dịch vụ trả phí.
